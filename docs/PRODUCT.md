# 产品方案与后续迭代

## 核心定位

面向普通用户的低压力防骗练习场。让用户在模拟的日常情境中，练习暂停、独立核验、守住账户、抵抗催促和及时止损。不是骗子话术生成器，也不是现实案件自动定性工具。

## 学习闭环

今日一局 → 读取消息 → 检查线索 → 作出选择 → 观察后果 → 逐步复盘 → 迁移问题 → 收藏知识 → 间隔复习。

区别于纯知识阅读：选择要改变状态，复盘要引用自己的路径，受损后仍可以停止加码。允许用户在故事中犯错，不给真实转账链接，不羞辱受害者。

## 当前信息架构

练习场、剧情、复盘、知识库、成长记录、设置、紧急止损、来源说明。移动端单列、桌面剧情与线索双列。大字模式、键盘导航、降低动画已提供。没有登录墙、排行榜和强制倒计时。

## 当前 AI 边界

自由文本输入生成当前场景内的角色回应。规则引擎掌控资金、隐私和终局；API 不接受模型新增动作。此版本不会生成整棵新剧情树，防止模型将错误建议变成通关答案。每局前端最多 8 次追问，服务端每 IP 每分钟最多 20 次请求。

## 优先迭代

1. 实际用户观察：邀请不同年龄的用户完成 3 个场景，记录不理解的词、卡住位置、结束后能否独立说出下一步。
2. 内容精审：逐条审核上游知识，给每篇增加官方依据、适用地区、发布日期、核验日期和责任编辑；当前 373 篇是参考区，不是审定教材。
3. 增加“正常但需核实”的对照场景，避免所有陌生互动都被条件反射当作诈骗。
4. 更丰富的剧情：身份差异、可信同伴对话、情境变体与阶段解锁。仍由经过审查的动作构成结局。
5. AI 导演实验：结构化提出候选剧情，离线审核后入库；不要把未经校验的生成剧情直接给学习者。
6. 家庭共学：一人操作、一人说明理由，提供打印的讨论卡；不将家庭成员真实经历上传公共服务。
7. 多租户部署前补充用户认证、服务端配额、共享限流存储、成本计量和密钥轮换。

## 验证效果

先看延迟迁移题正确率、是否会独立寻找官方入口、是否在沉没成本压力下停止，而不是仅看使用时长和练习分。没有采集埋点；若将来加入，先设计最小化、可退出的匿名方案。
