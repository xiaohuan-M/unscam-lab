# 3.2 发布验收

验证环境：Node.js 24.19.0，本地 Chromium 141（Playwright 1.56.1）。

## 已验证

- 46 项 Node 测试：所有编写分支与结局、余额边界、止损不返还损失、非法行动、可重放存档、v1 迁移、备份合并、敏感字段排除、复习日期、日期时区、合法 AI 动作、提示上下文、请求认证、跨来源、限流、日预算、超时、错误响应、真实本地 HTTP 兼容服务联调。
- 39 项 Chromium E2E：全部页面、完整剧情、正常对照、延迟解析、迁移题首答、错题记录、刷新续玩、损坏存档、搜索与分页、复习、导入导出、AI 成功/错误、离线完整故事、键盘操作与弹窗关闭、慢配置加载保留输入、无 API 的子路径静态站点离线完整流程。
- 完整收录验证：373 篇全部字段与 8,248 个正文块、65 个原文件逐字节比对、全文深链、自查保存、下载与经典游戏、离线资料、推理存档进入统一备份。
- 原作玩法：16 个场景的 395 条结束路径、十二局确定性抽取、二次诈骗连锁、零扣款的账号风险、借款确认、止损不返款、存档重放和统一备份。
- 微信式交互：默认进入原作、逐条消息与跳过、暂停续玩、转账只结算一次、AI 建议确认、Key 与自由文本不持久化、主题切换不打断当前对话、离线完整闯关。
- 保留扩展练习：16 个联系人与筛选、进行中对话续聊、线索快捷键、深色与大字下自由回复。
- 布局宽度 320 / 390 / 768 / 1440，加测 844×390 横屏；检查页面横向溢出、剧情、大字模式。
- 查看原作微信聊天的桌面、手机与深色大字实际截图；README 截图来自当前应用。
- 静态构建生成完整 public 资源和按内容计算的离线缓存版本；导航缓存统一剔除片段及查询串。
- Sites 预览实际验证原作入口、续玩和基础自由回复；9 项网关测试包含原作节点、BYOK、身份 / 来源校验、超时和预算。

## 边界

模型协议联调使用自建的本地 HTTP 测试服务，未使用第三方付费账户或真实用户 Key。不同商业提供商的模型行为仍需部署者通过“测试连接”与实际剧情验收。

手机布局验证是 Chromium 窗口模拟，未实际运行 iOS Safari / Android Chrome 真机或安装 PWA 到手机。发布前若目标是这些平台，应补充真机兼容性检查。

本地与 CI 验证保证已覆盖的行为，不等于证明用户的防骗能力得到提升。教学效果仍需实际受众的迁移测评。
