# 验证记录与发布验收

已执行：npm test（10/10 通过）、npm run check（通过）。Node.js v24.19.0。

测试内容：遍历 12 场景的所有编写分支、所有终局可达、资金与隐私边界、终局不可继续、未知动作拒绝、止损不退款、复习日期、首页与静态安全头、配置不泄露密钥、错误口令、跨来源、无效节点、模型伪造动作不生效、坏 JSON 回退、公开绑定的访问口令要求。

尚未完成：真实模型/付费 Key 联调；桌面和移动端实际浏览器 E2E、截图视觉检查、真实设备 PWA 安装。远程浏览器无法连接开发容器的 localhost，因此不将代码层检查宣称为视觉验收。

手工验收步骤：
1. 1440px 桌面、768px 平板、390px 手机和 320px 窄屏打开首页，检查无横向溢出、导航可达、按钮可触摸。
2. 进入快递场景 → 加好友 → 转 500 → 停止。结果应为 9500、及时止损；再次进入重玩不改变此前最高分。
3. 过程中刷新，点击继续；核对状态一致。完成后刷新不能重复计数。
4. 搜索“验证码”、切换类别、翻页；空结果有明确提示；添加复习、回答掌握程度、导出再导入。
5. 断网重开已完整加载的应用；基础资源应可用；AI 不应被离线缓存。
6. 设置临时 Key 后刷新，Key 清空；导出的备份不含 Key 和对话。
7. 无效模型 Key/返回坏 JSON/超时，仍能继续点击本地选项。
8. 键盘 Tab 走完导航、对话选择、弹窗；Escape 关闭弹窗；大字模式不遮挡内容。
9. 公网部署检查 HTTPS、访问口令、反代日志不记录请求体与敏感请求头、流量配额。
