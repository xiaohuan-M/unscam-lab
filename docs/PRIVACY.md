# 隐私说明

基础模式无登录、无广告、无埋点。应用加载静态资源后，剧情选择、成绩、复习日期和模式保存在当前浏览器的 localStorage。可导出迁移，也可在设置中确认清空。

自由输入的对话只保存在页面内存，不写入学习记录；刷新清空。AI Key、访问口令和 AI 开关同样仅在页面内存。备份只包含成绩、复习、模式等白名单字段，不含对话与凭据。

用户主动启用 AI 后，当前虚构场景、最近六条对话、本次输入会发送到部署者配置的模型服务。服务器使用环境变量 Key 或用户本次提供的 Key。服务商可能按自己的条款处理数据，部署者应事先了解并告知使用者。

输入检查会拦截连续长数字、邮箱和部分密钥形态，但无法识别所有个人信息；不要在模拟对话中粘贴真实事件资料。现实止损材料清单不会上传任何附件。

服务器没有数据库或对话日志；反向代理、宿主机、模型服务商可能另有日志策略。自托管者需自行控制这些日志，应用无法替它们承诺不留存。
